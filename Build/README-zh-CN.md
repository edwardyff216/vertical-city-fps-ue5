# 垂直城寨 FPS · Windows 试玩版 0.6.0-rc.2

解压整个 Windows 文件夹，双击顶层的 VerticalCityFPS.exe。遇到缺少 Microsoft 运行库提示时，使用 Prerequisites 文件夹中的 x64 安装程序。游戏进入中文出战准备页，可先调整主副手、技能与配置，再点击「出战」。

| 操作 | 按键 |
|---|---|
| 移动、跳跃 | WASD、空格 |
| 跑步、滑铲 | 左 Shift、跑动中按左 Ctrl |
| 开火或挥刀 | 鼠标左键 |
| 举枪瞄准或武士刀突进斩 | 鼠标右键 |
| 换弹、格挡 | R、F |
| 主手、副手、切换武器 | 1、2、Q |
| 两个小技能、大招 | C、X、G |
| 切换第一或第三人称、暂停 | V、Esc |

清完普通房后，先领本房奖励，再点一张写有遭遇与奖励的房卡。走过卡面指定的门才会进入下一房。四个普通房之后是首领房。前三次均走上门会遇到镜塔哨卫，均走下门会遇到炉心破阵者，混合路线会遇到中继织盾者。击败首领后进入撤离区域结算。

「装备」页下方可以从 Godot 的 profile.json 导入到独立槽。「返回 UE 原档」可切回原有 UE 进度。战斗中直接退出会按中断出战处理，建议带着想保留的装备走到撤离区。

出战准备页可进入词条测试房，分别试用武士刀、枪械触发和冰电组合，也可以自选武器与词条。离开测试房后回到原存档。击败路线首领后，两把卡面指定类型的武器直接入包，穿过撤离门完成结算。
